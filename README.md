# 陶艺工作室装窑预检（Kiln Pre-check）

在坯体入窑烧制前，于浏览器中摆放矩形窑室内的可旋转矩形坯体，系统按**线膨胀**随温升放大坯体外廓，用**旋转矩形分离轴定理（SAT）**检测坯体间与窑壁接触，并求出升温至目标温度过程中的**最早接触温度**，高亮涉事对象。任何参数修改立即重算，方案自动持久化到本地 JSON。

## 快速启动（单条命令）

```bash
docker compose up --build
```

启动后访问：**http://localhost:3000**

> 依赖安装（`npm install`）与初始化（数据目录、`plans.json` 创建）均已纳入镜像构建与容器启动流程，无需额外步骤。方案数据通过命名卷 `kiln-data` 持久化。

也可以使用 Docker 单容器方式：

```bash
docker build -t kiln-precheck . && docker run -d -p 3000:3000 -v kiln-data:/app/data kiln-precheck
```

## 本地开发

```bash
npm install
npm start          # 访问 http://localhost:3000
npm test           # 运行几何核心单元测试
```

## 功能与操作

- **窑室与温度**：设置矩形窑室宽/高（mm）、起始温度与目标温度（°C）。
- **坯体**：矩形坯体，参数为中心坐标、宽/高、旋转角、线膨胀系数 α（×10⁻⁶/K）。
- **画布交互**：
  - 左键拖拽移动坯体；拖动黄色手柄或滚轮旋转（Shift 微调）；
  - 双击空白处在该位置添加坯体；`Delete` 删除选中坯体，方向键微调位置；
  - 黄色虚线为预览温度下膨胀后的外廓，预览温度可用滑块在起始~目标间拖动。
- **实时预检**：任何修改立即重算——
  - 绿色：升至目标温度全程无接触；
  - 红色：给出最早接触温度与涉事对象（坯体↔坯体 / 坯体↔窑壁），画布中以红色高亮并连线标记；
  - 起始温度下已重叠会单独警示。
- **方案管理**：多方案保存/载入/删除，修改后自动保存；支持导出/导入 JSON 文件。

## 计算原理

- **线膨胀**：`尺寸(T) = 尺寸(T₀) × (1 + α·(T − T₀))`，膨胀绕坯体中心进行。
- **接触检测**：对两个旋转矩形取各自两条边法向共 4 条投影轴，所有轴上投影区间均重叠则两矩形相交（SAT）；坯体任一角点越出窑室矩形即判定触壁。
- **最早接触温度**：膨胀关于温度单调（坯体只增不减），接触谓词单调，故在 `[起始温度, 目标温度]` 上对每对坯体、每个坯体-窑壁分别二分求最早接触温度（64 次迭代，精度远高于 0.01°C），取全局最小值。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/plans` | 列出全部方案名与当前方案 |
| GET | `/api/plans/:name` | 读取方案 |
| PUT | `/api/plans/:name` | 保存（新建/覆盖）方案 |
| DELETE | `/api/plans/:name` | 删除方案 |
| POST | `/api/autosave` | 自动保存当前工作方案 |

方案 JSON 结构：

```json
{
  "kiln": { "width": 600, "height": 450, "startTemp": 20, "targetTemp": 1300 },
  "bodies": [
    { "id": "b1", "name": "茶碗 A", "x": 150, "y": 120, "w": 120, "h": 90, "angle": 12, "alpha": 6 }
  ]
}
```

数据文件默认位于 `data/plans.json`（容器内 `/app/data/plans.json`），可用环境变量 `DATA_DIR` 覆盖；端口用 `PORT` 覆盖（默认 3000）。
